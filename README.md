# MCT Students' Union

A student-led digital hub for MCT College of Legal Studies, Melmuri, Malappuram.

## Included in this first version

- Responsive homepage and student hub layout
- Dedicated areas for the 5-year BBA LL.B (Hons.) and 3-year LL.B (Unitary) programmes
- Entry points for previous question paper libraries
- Student grievance portal placeholder
- Notices and student announcements section

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Important setup before accepting submissions

The grievance portal and question-paper libraries are currently interface placeholders. No grievance information or attachments are collected or stored by this version. Before enabling submissions, connect a secure backend with authentication, private storage, role-based access for authorised student representatives, and a private tracking workflow.

Use the official college gallery only for verified MCT College of Legal Studies campus imagery. This is an independent student-led resource website and should not be represented as the college's official website.
