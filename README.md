# MCT Students' Union

A responsive, student-led digital hub for MCT College of Legal Studies, Melmuri, Malappuram.

## Current frontend

- Responsive student hub homepage
- Separate programme entry points for 5-year BBA LL.B (Hons.) and 3-year LL.B (Unitary)
- Resource landing areas for 10-semester and 6-semester previous-paper libraries
- Student grievance portal information area
- Notices and student announcement section
- Mobile responsive styling and accessibility-conscious semantic markup

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before enabling student services

The question-paper libraries and grievance portal are currently frontend landing areas, not connected services. No grievance submissions, attachments, or student data are collected or stored. Before accepting complaints, implement a secure backend with authentication, private storage, role-based access for authorised student representatives, abuse protection, and private reference-based tracking. Do not publish grievance details.

Add only verified MCT College of Legal Studies images from the official college gallery: https://mctlawcollege.org/gallery.php. Do not use images from KMCT or MCT Training College.

This is an independent student-led resource website and must not be represented as the official college website without authorisation.
